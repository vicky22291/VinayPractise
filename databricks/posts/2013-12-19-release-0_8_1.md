# Apache Spark 0.8.1 Released

- Source: https://www.databricks.com/blog/2013/12/19/release-0_8_1.html
- Published: 2013-12-19
- Authors: Patrick Wendell
- Categories: engineering, open-source
- Images: 0 total, 0 extracted as architecture

We are happy to announce the release of Apache Spark 0.8.1. In addition to performance and stability improvements, this release adds three new features. First, Spark now supports for the newest versions of YARN (2.2+). Second, the standalone cluster manager supports a high-availability mode in which it can tolerate master failures. Third, shuffles have been optimized to create fewer files, improving shuffle performance drastically in some settings.

In conjunction with the Apache Spark 0.8.1 release we are separately releasing [Spark In MapReduce (SIMR)](https://www.databricks.com/blog/2014/01/01/simr.html), which enables seamlessly running Spark on [Hadoop](https://www.databricks.com/glossary/hadoop) [MapReduce](https://www.databricks.com/glossary/mapreduce) v1 clusters without requiring the installation of Scala or Spark.

While Apache Spark 0.8.1 is a minor release, it includes these larger features for the benefit of Scala 2.9 users. The next major release of Apache Spark, 0.9.0, will be based on Scala 2.10.

This release was a community effort, featuring contributions from more than 40 developers. For much more information about Apache Spark 0.8.1, head over to the [release notes](https://spark.incubator.apache.org/releases/spark-release-0-8-1.html) or [download Apache Spark 0.8.1](https://spark.incubator.apache.org/downloads.html) and try it out for yourself.
