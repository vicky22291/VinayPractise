Here’s our recap of what’s transpired with Apache Spark since our [previous digest](https://www.databricks.com/blog/2016/08/08/databricks-bi-weekly-digest-8816.html).

- Databricks CTO and Co-founder Matei Zaharia presented “Unifying big data workloads in Apache Spark” at [@Scale Conference](https://atscaleconference.com/events/main-event/).
- Databricks CTO and Co-founder Matei Zaharia talked with SiliconAngle/theCUBE about [How Apache Spark is transforming apps with data streaming](https://siliconangle.com/2016/08/17/streaming-batch-and-interactive-the-synergy-of-end-to-end-data-apps/).
- Tim Hunter released two Apache Spark packages: [GraphFrames Package](https://spark-packages.org/package/graphframes/graphframes) and [scikit-learn package 0.2.0](https://pypi.org/project/spark-sklearn/0.2.0/) (with support for fitting keyed models—e.g., fitting 1 model per customer).
- Tim Hunter presented at the Bay Area Spark Meetup @ Salesforce: [TensorFrames on Google’s TensorFlow and Apache Spark](https://www.meetup.com/spark-users/events/232428471/).
- Joseph Bradley answered on SiliconAngle/theCUBE: [Can Apache Spark do for machine learning what it’s has done for data?](https://siliconangle.com/2016/08/17/can-spark-do-for-machine-learning-what-its-done-for-data/)
- Spark Community Evangelist Jules Damji blogged on [How to use SparkSession in Apache Spark 2.0](https://www.databricks.com/blog/2016/08/15/how-to-use-sparksession-in-apache-spark-2-0.html).
- Pavel Hardak of Basho demonstrated the [Riak Integration and connector to Apache Spark 2.0](https://www.databricks.com/blog/2016/08/11/the-quest-for-hidden-treasure-an-apache-spark-connector-for-the-riak-nosql-database.html)
- Burak Yavuz showed in a webinar how Apache Spark is used to [simplify log ETL Pipeline](https://www.databricks.com/blog/2016/08/16/databricks-data-pipeline-on-demand-webinar-faq.html).
- Michael Armbrust explained aspects of declarative programming on SiliconAngle/theCUBE: [Just do it: Declarative programming for simplifying data queries](https://siliconangle.com/2016/08/17/just-do-it-declarative-programming-for-simplifying-data-queries/).
- Databricks VP of Engineering Patrick Wendell interviewed by SiliconAngle/theCUBE: [Double-team: The software/hardware sandwich that’s taking data up a level](https://siliconangle.com/2016/08/17/double-team-the-softwarehardware-sandwich-thats-taking-data-up-a-level/).
