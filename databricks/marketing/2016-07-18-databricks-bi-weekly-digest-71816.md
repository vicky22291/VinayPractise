Today, we're kicking off a new series: the Databricks Bi-Weekly Digest. Our goal with this digest is to summarize Spark related content, compiled by Databricks, for the community. It will cover Spark technical content: blog posts, meetups tech-talks, conference talks, and noteworthy news articles pertaining to Apache Spark.

Here’s what’s happened in the last two weeks:

- A hands on Tutorial how to use SparkR presented at the useR 2016 conference: [SparkR Tutorials at useR 2016](https://www.databricks.com/blog/2016/07/07/sparkr-tutorial-at-user-2016.html). Peruse through presentations and try the Notebooks in Databricks.
- Vote for [Apache Spark 2.0 RC4 Update](http://apache-spark-developers-list.1001551.n3.nabble.com/VOTE-Release-Apache-Spark-2-0-0-RC4-td18317.html) from Reynold Xin is underway.
- JIRAs closed:
  - [Experimental support for Kafka 0.10 in Spark 2.0](https://issues.apache.org/jira/browse/SPARK-12177)
- Want to be heard, want to share your thoughts? Please take our [Databricks 2016 Apache Spark Survey](https://www.surveymonkey.com/survey-closed/?sm=_2Fvl_2FEqaMrDe2YMjCd6P05cvqv3AjiqD8iXTmxONljh8tMAPREb8u8bh4v_2B2Kou_2FVTh141gSa06dF4ZgZVa50PoUOgiD9tno44FsekE8QPS8_3D) and make a difference.
- Tim Hunter presented [Combining Machine Learning Frameworks with Apache Spark](https://www.slideshare.net/databricks/combining-machine-learning-frameworks-with-apache-spark) at the Hadoop Summit.
- Databricks released [Stanford CoreNLP wrapper for Apache Spark](https://spark-packages.org/package/databricks/spark-corenlp) with an [example notebook](https://databricks-prod-cloudfront.cloud.databricks.com/public/4027ec902e239c93eaaa8714f173bcfc/1233855/3233914658600709/588180/latest.html). Try it on Databricks.
- Joseph Bradley spoke at the NYC Spark Meetup: [Distributed ML in Apache Spark Meetup Tech Talk](https://www.slideshare.net/databricks/distributed-ml-in-apache-spark). Learn about DataFrames in MLlib.
- A blog explained [A Tale of Three Apache Spark APIs: RDDs, DataFrames, and Datasets](https://www.databricks.com/blog/2016/07/14/a-tale-of-three-apache-spark-apis-rdds-dataframes-and-datasets.html). Find out when to use which API and why.
- Three Apache Spark related tech-talks presented at [Bay Area Apache Spark Meetup Tech-Talks @ SAP](https://www.meetup.com/spark-users/events/231574440/comments/467682517/). You can [watch the video](https://www.youtube.com/watch?v=VGzPTRCSVh8) on YouTube.
