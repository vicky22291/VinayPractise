On March 7th, our team hosted a live webinar—[Managing the Complete Machine Learning Lifecycle](https://pages.databricks.com/201903-US-WB-Managing-the-Complete-Machine-Learning-Lifecycle-Reg.html)—with Andy Konwinski, Co-Founder and VP of Product at Databricks.

In this webinar, we walked you through how MLflow, an open source framework for the complete Machine Learning lifecycle, helps solve for challenges around experiment tracking, reproducible projects and model deployment. Specifically, we covered:

- [Open source MLflow](http://www.mlflow.org) and overview of its core components: MLflow Tracking, MLflow Project, and MLflow Model.
- [Managed MLflow](https://www.databricks.com/blog/2019/03/06/managed-mlflow-on-databricks-now-in-public-preview.html) and how it integrates with the Databricks Unified Analytics Platform (now available to all customers at no additional cost).

In particular, we showed you how to:

- Keep track of experiments runs and results across ML frameworks.
- Execute projects remotely on to a Databricks cluster, and quickly reproduce your runs.
- Quickly productionize models using Databricks production jobs, Docker containers, Azure ML, or Amazon SageMaker.

We demonstrated these concepts using [notebooks and tutorials](https://docs.databricks.com/applications/mlflow/index.html) from our public documentation so that you can practice at your own pace.
